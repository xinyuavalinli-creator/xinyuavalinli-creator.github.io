# AVALIN LI — Architecture & Design

Bilingual personal portfolio of Xinyu (Avalin) Li.

Static HTML, CSS, JavaScript, and local image assets. Open `index.html` through a local HTTP server to preview.

## Publishing

GitHub Pages: deploy the `main` branch from `/ (root)`. The `.nojekyll` file preserves the static site as authored.

## Content

Eight portfolio projects, Chinese and English versions, project image galleries, the Bungee Space comic reader, and CV.
